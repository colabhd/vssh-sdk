# docs

O portal de quem escreve um vssh-app: os conceitos (o que é um app, a janela, a ponte com o
ambiente, o manifesto, a publicação) e os guias, escritos à mão. A referência de API (o schema, a
ABI da ponte, os typings) é gerada pelo sistema em [`api/`](../api/) e fica fora daqui; o que
mora aqui explica, e o que mora lá declara.

Os guias chegam com a próxima etapa; enquanto isso o [`README.md`](../README.md) da raiz e o
[`MIGRATION.md`](../MIGRATION.md) são a documentação.
